## Descrição

Como usuário do Gym Hub, quero receber feedback imediato durante o treino:
1. Um **timer de descanso** que inicia automaticamente após salvar uma sessão
2. Um **badge de PR** quando bato meu recorde pessoal de carga
3. O **volume total acumulado** do treino atual em tempo real

Esses três elementos transformam o app num parceiro ativo durante o treino, não apenas um log passivo.

## Acceptance Criteria

### AC-01: Hook useRestTimer
- [ ] Criar `useRestTimer(defaultSeconds?: number)` (default: 90)
- [ ] Retorna `{ isRunning, secondsLeft, start(secs?), stop(), reset(), setDuration(secs) }`
- [ ] Faz contagem regressiva com `setInterval` de 1s
- [ ] Ao chegar em 0: `isRunning = false`, dispara `navigator.vibrate([200, 100, 200])` se disponível
- [ ] Timer persiste enquanto o componente está montado (não para ao scrollar)

### AC-02: RestTimerWidget — interface
- [ ] Criar `RestTimerWidget` que aparece como banner fixo na parte inferior do ExerciseCard após salvar sessão
- [ ] Mostra contagem regressiva em formato `1:30`, `0:45`, etc.
- [ ] Barra de progresso visual (linha que encolhe junto com o tempo)
- [ ] Botões rápidos para mudar duração: 60s | 90s | 120s | ✕
- [ ] Quando acaba: mostra "✓ Descanse!" e some após 3 segundos
- [ ] Pode ser dispensado a qualquer momento com ✕
- [ ] Dark mode completo

### AC-03: Timer inicia automaticamente após Salvar Sessão
- [ ] No ExerciseCard, ao chamar `logSession` com sucesso → `restTimer.start()` automaticamente
- [ ] Se timer já está rodando → reinicia do início
- [ ] O timer é **por exercício** (cada ExerciseCard tem seu próprio timer)

### AC-04: PR Detection + Badge
- [ ] Em `useExerciseSessions`, após salvar sessão com sucesso, comparar `weight` com o máximo histórico
- [ ] Buscar máximo: `MAX(weight)` do histórico anterior (excluindo a sessão recém salva)
- [ ] Se `weight > maxHistorical` → `isNewPR = true`
- [ ] Criar `PRBadge` component: `🏆 Novo PR!` com animação de entrada (scale + fade-in)
- [ ] PRBadge aparece no ExerciseCard ao lado do nome do exercício por 5 segundos, depois some
- [ ] Não aparece se não há histórico anterior (primeira sessão nunca é PR)
- [ ] Dark mode: cores vibrantes que se destacam em ambos os temas

### AC-05: Volume Total do Treino Atual
- [ ] No GymPage, calcular volume do treino ativo em tempo real
- [ ] `volume = Σ(exercise.weight × parseInt(exercise.reps))` para todos os exercícios do workout ativo
- [ ] Exercícios com reps não-inteiros (ex: "3x10") contribuem 0 (não quebrar o cálculo)
- [ ] Mostrar no topo da lista de exercícios: "Volume: 3.240 kg" ou "Volume: 1.2 t" (se > 1000)
- [ ] Atualiza em tempo real conforme usuário edita peso/reps (usa os valores locais)
- [ ] Só aparece quando há pelo menos 1 exercício com peso > 0 e reps inteiro
- [ ] Dark mode

## Technical Notes (Aria)

**useRestTimer — timer puro:**
```ts
const useRestTimer = (defaultSeconds = 90) => {
  const [secondsLeft, setSecondsLeft] = useState(0)
  const [isRunning, setIsRunning] = useState(false)
  const intervalRef = useRef<ReturnType<typeof setInterval> | null>(null)

  const start = (secs = defaultSeconds) => {
    if (intervalRef.current) clearInterval(intervalRef.current)
    setSecondsLeft(secs)
    setIsRunning(true)
    intervalRef.current = setInterval(() => {
      setSecondsLeft(prev => {
        if (prev <= 1) {
          clearInterval(intervalRef.current!)
          setIsRunning(false)
          navigator.vibrate?.([200, 100, 200])
          return 0
        }
        return prev - 1
      })
    }, 1000)
  }
  // ...cleanup no useEffect return
}
```

**PR detection:** buscar histórico ANTES de inserir, comparar com `weight` atual  
**Volume:** computed no render do GymPage — zero novo estado
