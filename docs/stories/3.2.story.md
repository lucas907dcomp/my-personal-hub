## Descrição

Como usuário do Gym Hub, quero uma tela Dashboard que mostre minha performance consolidada — streak de
treinos, total de sessões, recordes pessoais (PRs) e volume semanal — para ter motivação e uma visão
rápida de como estou evoluindo sem precisar abrir exercício por exercício.

**Analogia:** O mesmo papel que o DashboardView faz no Productivity Hub, mas para dados de treino.

## Technical Notes (Aria)

**Streak algorithm:**
```ts
// Pegar datas únicas de sessões, ordenar DESC
// Verificar se formam sequência consecutiva a partir de hoje/ontem
function calcStreak(sessions: { loggedAt: string }[]): number {
  const uniqueDates = [...new Set(sessions.map(s => s.loggedAt.slice(0, 10)))].sort().reverse()
  if (uniqueDates.length === 0) return 0
  let streak = 0
  let expected = todayStr() // ou yesterdayStr() se não há sessão hoje
  for (const date of uniqueDates) {
    if (date === expected) { streak++; expected = prevDay(expected) }
    else if (date < expected) break
  }
  return streak
}
```

**Tab switching:** state local no GymPage `type GymView = 'workouts' | 'dashboard'`  
**useGymStats:** busca `tb_gym_sessions` com join em `tb_gym_exercises` para nomes
