# STORY-015 — Tags de Grupo Muscular + Notas por Sessão + Reordenar Exercícios

**Epic:** EPIC-003 — Gym Hub: Analytics & Experience  
**Sprint:** 14  
**Status:** Draft  
**Complexity:** M (5 pts)  
**Created:** 2026-05-27  
**Owner:** @dev (Dex)

## Descrição

Como usuário do Gym Hub, quero poder organizar meus exercícios por grupo muscular, adicionar notas
rápidas em cada sessão para contexto, e reordenar os exercícios dentro de um treino para que a lista
reflita minha sequência real de treino.

---

## Acceptance Criteria

### AC-01: Migração de schema — muscle_group e position
- [ ] Migration SQL: `ALTER TABLE tb_gym_exercises ADD COLUMN muscle_group text`
- [ ] Migration SQL: `ALTER TABLE tb_gym_exercises ADD COLUMN position integer DEFAULT 0`
- [ ] Migration SQL: `ALTER TABLE tb_gym_sessions ADD COLUMN notes text`
- [ ] Aplicar migrations no Supabase (via `supabase db push` ou SQL direto)
- [ ] Dados existentes: `muscle_group = NULL` (não quebra nada), `position` preenchido via update incremental na carga inicial

### AC-02: Seletor de grupo muscular no AddExerciseForm
- [ ] Adicionar campo "Grupo Muscular" no AddExerciseForm
- [ ] Opções: Peito · Costas · Ombros · Bíceps · Tríceps · Pernas · Core · Cardio
- [ ] Seleção visual: chips clicáveis com ícone e cor por grupo (não dropdown)
- [ ] Cores:
  - Peito: azul / Costas: roxo / Ombros: laranja
  - Bíceps: verde / Tríceps: amarelo / Pernas: vermelho
  - Core: rosa / Cardio: ciano
- [ ] Campo opcional (pode salvar sem grupo muscular)
- [ ] Dark mode completo

### AC-03: MuscleGroupBadge no ExerciseCard
- [ ] Criar `MuscleGroupBadge` component com a cor do grupo
- [ ] Exibir badge no header do ExerciseCard ao lado do nome do exercício (se `muscle_group !== null`)
- [ ] `useExercises` atualizado para incluir `muscle_group` no select e map
- [ ] Dark mode

### AC-04: Filtro por grupo muscular no GymPage
- [ ] Adicionar barra de filtro chips horizontal acima da lista de exercícios (abaixo do WorkoutSelector)
- [ ] Chips: "Todos" + um chip por grupo muscular presente nos exercícios do treino ativo
- [ ] Filtro é local (client-side), zero chamada extra ao Supabase
- [ ] "Todos" selecionado por default, reset ao trocar de workout
- [ ] Se todos os exercícios do treino são do mesmo grupo, barra de filtro fica oculta

### AC-05: Notas por sessão no ExerciseCard
- [ ] Ao clicar em "Salvar Sessão", expandir um campo de notas ANTES de confirmar
- [ ] Campo: textarea pequeno (2 linhas) com placeholder "Notas opcionais... (dor, energia, ambiente)"
- [ ] Botão "Salvar com nota" e "Salvar sem nota" (skip)
- [ ] Nota salva em `tb_gym_sessions.notes`
- [ ] Exibir nota da última sessão no ExerciseCard abaixo do "Último treino" (truncada a 60 chars + "...")
- [ ] HistoryModal (STORY-012) exibe nota em cada item do histórico se presente
- [ ] Dark mode

### AC-06: Reordenar exercícios dentro do workout
- [ ] No painel "Gerenciar Divisão de Treino" (WorkoutSelector), adicionar modo de reordenação de exercícios
- [ ] OU: no próprio GymPage, adicionar botões ▲ ▼ no ExerciseCard (modo gerenciar)
- [ ] Decisão: adicionar botão "Reordenar" na lista de exercícios → entra em modo drag com ▲▼
- [ ] Ao reordenar → atualizar `position` em `tb_gym_exercises` para todos os exercícios do workout
- [ ] Mesma lógica de swap usada em workouts (sem drag-and-drop lib)
- [ ] Dark mode

## Scope

**IN:**
- Migrations (muscle_group, position em exercises; notes em sessions)
- Seletor visual de grupo muscular no AddExerciseForm
- MuscleGroupBadge no ExerciseCard
- Filtro chips por grupo no GymPage
- Notas por sessão (campo + exibição)
- Reordenação de exercícios (botões ▲ ▼)

**OUT:**
- Filtro de exercícios across múltiplos workouts
- Estatísticas de volume por grupo muscular (Backlog pós-epic)
- Drag and drop nativo
- Edição retroativa de notas (histórico é imutável)
