## Descrição

Como usuário do Gym Hub, quero registrar meu peso corporal diário e ver sua evolução em um gráfico,
além de poder personalizar quais suplementos rastreio (não só Whey e Creatina) — para ter uma visão
completa de saúde e hábitos integrada ao meu app de treino.

## Acceptance Criteria

### AC-01: Migração de schema — tb_body_weight e tb_supplement_config
- [ ] Migration SQL:
```sql
CREATE TABLE tb_body_weight (
  id          uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id     uuid REFERENCES auth.users NOT NULL,
  date        date NOT NULL DEFAULT CURRENT_DATE,
  weight_kg   numeric(5,2) NOT NULL,
  created_at  timestamptz DEFAULT now(),
  UNIQUE(user_id, date)
);
ALTER TABLE tb_body_weight ENABLE ROW LEVEL SECURITY;
CREATE POLICY "users own body weight" ON tb_body_weight
  USING (auth.uid() = user_id)
  WITH CHECK (auth.uid() = user_id);

CREATE TABLE tb_supplement_config (
  id       uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id  uuid REFERENCES auth.users NOT NULL,
  name     text NOT NULL,
  icon     text DEFAULT '💊',
  position integer DEFAULT 0,
  created_at timestamptz DEFAULT now()
);
ALTER TABLE tb_supplement_config ENABLE ROW LEVEL SECURITY;
CREATE POLICY "users own supplement config" ON tb_supplement_config
  USING (auth.uid() = user_id)
  WITH CHECK (auth.uid() = user_id);
```
