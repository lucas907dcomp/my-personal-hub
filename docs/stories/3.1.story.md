## Descrição

Como usuário do Gym Hub, quero ver minha evolução de carga ao longo do tempo para cada exercício, com
um gráfico de linha mostrando o histórico de sessões e uma lista completa das últimas sessões — para
saber que estou progredindo e tomar decisões de carga baseadas em dados reais.

**Problema atual:** O ExerciseCard mostra apenas "último treino". O banco `tb_gym_sessions` tem todo
o histórico mas o usuário nunca consegue visualizá-lo.

## Technical Notes (Aria)

```tsx
// useExerciseHistory.ts
export function useExerciseHistory(exerciseId: string, limit = 30) {
  const [sessions, setSessions] = useState<SessionPoint[]>([])
  const [loading, setLoading] = useState(true)
  useEffect(() => {
    supabase
      .from('tb_gym_sessions')
      .select('id, logged_at, weight, reps, rpe')
      .eq('exercise_id', exerciseId)
      .order('logged_at', { ascending: false })
      .limit(limit)
      .then(({ data }) => {
        setSessions((data ?? []).map(mapSessionPoint))
        setLoading(false)
      })
  }, [exerciseId])
  return { sessions, loading }
}
```
