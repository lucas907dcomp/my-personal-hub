**Module:** Gym Hub
**Purpose:** Named training splits (e.g., "Treino A — Push", "Treino B — Pull")

### `tb_gym_exercises`

**Java Entity:** `com.lucas.erp.gym.Exercise`
**Module:** Gym Hub
**Purpose:** Individual exercises within a workout split, including progressive overload tracking

```sql
CREATE TABLE tb_gym_exercises (
    id                UUID     NOT NULL DEFAULT gen_random_uuid(),
    workout_id        UUID,              -- logical FK to tb_gym_workouts.id — NO CONSTRAINT ⚠️
    name              VARCHAR,           -- nullable ⚠️
    weight            FLOAT8,            -- nullable (Double wrapper, not primitive)
    reps              VARCHAR,           -- flexible: "3x10", "12", "8-12" — not normalized ⚠️
    rpe               INTEGER,           -- nullable (Integer wrapper)
    can_increase_next BOOLEAN DEFAULT false,

    CONSTRAINT pk_gym_exercises PRIMARY KEY (id)
    -- MISSING: CONSTRAINT fk_exercises_workout FOREIGN KEY (workout_id) REFERENCES tb_gym_workouts(id) ⚠️
    -- MISSING: INDEX idx_exercises_workout_id ON tb_gym_exercises(workout_id) ⚠️
);
```

| Column | Type | Nullable | Default | Notes |
|--------|------|----------|---------|-------|
| `id` | `uuid` | NOT NULL | `gen_random_uuid()` | PK |
| `workout_id` | `uuid` | YES ⚠️ | — | Logical FK — no constraint, no index |
| `name` | `varchar(255)` | YES ⚠️ | — | Exercise name |
| `weight` | `float8` | YES | — | Load in kg |
| `reps` | `varchar(255)` | YES | — | Free-text format ("3x10") — not normalized |
| `rpe` | `int4` | YES | — | Rate of Perceived Exertion (1–10) |
| `can_increase_next` | `bool` | YES | `false` | Progressive overload flag |

### `tb_gym_supplements`

**Java Entity:** `com.lucas.erp.gym.SupplementGoal`
**Module:** Gym Hub
**Purpose:** Daily supplement intake tracking

```sql
CREATE TABLE tb_gym_supplements (
    id       INTEGER NOT NULL DEFAULT 1,  -- hardcoded singleton ⚠️ CRITICAL
    whey     BOOLEAN DEFAULT false,
    creatina BOOLEAN DEFAULT false,

    CONSTRAINT pk_gym_supplements PRIMARY KEY (id)
);
```

| Column | Type | Nullable | Default | Notes |
|--------|------|----------|---------|-------|
| `id` | `int4` | NOT NULL | `1` | **Singleton PK — hardcoded** ⚠️ |
| `whey` | `bool` | YES | `false` | Whey protein daily goal |
| `creatina` | `bool` | YES | `false` | Creatine daily goal |

**Critical:** This table can hold exactly one row (id=1). Completely incompatible with multi-tenancy. Must be redesigned.

**Target design:**
```sql
-- Post-migration target
CREATE TABLE tb_gym_supplements (
    user_id  UUID    NOT NULL,         -- replaces id=1
    whey     BOOLEAN NOT NULL DEFAULT false,
    creatina BOOLEAN NOT NULL DEFAULT false,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now(),

    CONSTRAINT pk_gym_supplements PRIMARY KEY (user_id),
    CONSTRAINT fk_supplements_user FOREIGN KEY (user_id) REFERENCES auth.users(id) ON DELETE CASCADE
);
```

### `tb_fuel_records`

**Java Entity:** `com.lucas.erp.fuel.FuelRecord`
**Module:** Fuel Hub
**Purpose:** Vehicle fuel fill-up history log

```sql
CREATE TABLE tb_fuel_records (
    id              UUID      NOT NULL DEFAULT gen_random_uuid(),
    date            TIMESTAMP DEFAULT now(),   -- fill-up datetime (not created_at)
    total_value     FLOAT8,                    -- R$ paid
    price_per_liter FLOAT8,                    -- R$/L
    odometer        FLOAT8,                    -- km
    liters          FLOAT8,                    -- calculated server-side
    fuel_type       VARCHAR,                   -- "gasoline", "ethanol", etc.

    CONSTRAINT pk_fuel_records PRIMARY KEY (id)
);
```

| Column | Type | Nullable | Default | Notes |
|--------|------|----------|---------|-------|
| `id` | `uuid` | NOT NULL | `gen_random_uuid()` | PK |
| `date` | `timestamp` | YES | `now()` | Fill-up date (domain field, not audit timestamp) |
| `total_value` | `float8` | YES | — | Total R$ paid |
| `price_per_liter` | `float8` | YES | — | Price per liter |
| `odometer` | `float8` | YES | — | Odometer reading at fill-up |
| `liters` | `float8` | YES | — | Calculated: `totalValue / pricePerLiter` |
| `fuel_type` | `varchar(255)` | YES | — | Unconstrained — no CHECK constraint |

**Type concern:** `FLOAT8` for monetary values (`total_value`, `price_per_liter`) introduces floating-point precision errors. `NUMERIC(10,2)` is the correct type for currency.

-- Verify all tables exist

FROM pg_tables
WHERE schemaname = 'public'
ORDER BY tablename;

-- Verify column types match this document
SELECT table_name, column_name, data_type, is_nullable, column_default
FROM information_schema.columns
WHERE table_schema = 'public'
ORDER BY table_name, ordinal_position;

-- Verify FK constraints (expect 0 rows — none defined)
SELECT
    tc.table_name, kcu.column_name,
    ccu.table_name AS foreign_table_name,
    ccu.column_name AS foreign_column_name
FROM information_schema.table_constraints AS tc
JOIN information_schema.key_column_usage AS kcu
    ON tc.constraint_name = kcu.constraint_name
JOIN information_schema.constraint_column_usage AS ccu
    ON ccu.constraint_name = tc.constraint_name
WHERE tc.constraint_type = 'FOREIGN KEY'
  AND tc.table_schema = 'public';

-- Verify indexes
SELECT tablename, indexname, indexdef
FROM pg_indexes
WHERE schemaname = 'public'
ORDER BY tablename;
